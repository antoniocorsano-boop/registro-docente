# AIC-03 REVIEW v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the current metadata-only REVIEW panel with a privacy-safe, local-first contextual didactic review that explains usefulness, evidence, planning alignment, gaps, reuse possibilities, confidence and limitations without mutating product state.

**Architecture:** Keep `review-source` and the existing Contextual Copilot Core authority unchanged. Add a reusable current-target relevance primitive, then a pure `contextualDidacticReview` engine that combines current Teaching Context, deterministic Library relevance evidence and authoritative Planning/Arena evidence; render the result in the existing `LibraryCopilotComposer`. REVIEW analysis itself adds no network path and no persistence path; the already-qualified Agent-First intent interpreter and local fallback remain the entry routing layer.

**Tech Stack:** React 19, TypeScript, Bun, existing `@trama/contextual-copilot-core`, existing deterministic relevance resolver, Planning/Arena context bridge, GitHub Actions exact-SHA qualification, Playwright 1.64.1.

**Spec:** `docs/superpowers/specs/2026-10-27-aic-03-review-v2-design.md`

## Global Constraints

- Frozen predecessor baseline: `main@5cd4b1f7d774aea2699b42320c9a54832d752c0d`.
- `review-source` remains capability `REVIEW`, risk `PROPOSE`; Contextual Copilot Core authority is unchanged.
- REVIEW v2 is analysis only: no Library/UDA/Planning/memory write and no call to the AIC-02 compound adoption boundary.
- No new provider, model, secret, timeout, retry, endpoint or remote REVIEW data flow.
- No professional-memory implementation in AIC-03; AIC-05 remains the memory foundation.
- No AI budget-governor implementation in AIC-03; AIC-06 remains the escalation foundation.
- `unknown`, `student-personal`, `restricted` and `failed` sources do not enter detailed didactic review as safe professional content.
- Planning alignment is evidence-based: a Planning Context or current UDA alone is not proof of specific curricular alignment.
- Existing LINK remains Core-authorized + human-confirmed.
- Existing PREPARE disclosure, one-shot remote consent and AIC-02 adoption semantics remain unchanged.
- Existing `registro.agent-routing-request/v1` wire contract remains unchanged and receives no source/document content.
- Existing `resolveLibraryRelevance()` ranking semantics remain compatible for current consumers, including exclusion of already-linked suggestion targets.
- No raw numeric relevance score is shown to the teacher.
- Causal RED → GREEN for every changed contract/behavior.
- Exact-candidate SHA must be declared and verified by every qualification gate.
- Automatic/browser qualification uses synthetic-only data.
- Canonical browser certification is GitHub-hosted Playwright 1.64.1 on the exact candidate.
- Technical qualification does not authorize merge, deploy or publication.

## Review Focus

1. **Context-only false confidence** — a source that is merely attached to the current class/UDA but has no lexical or curriculum evidence must stay `weak`; Task 2 pins this.
2. **Already-linked current target** — the current UDA/lesson remains reviewable even though the suggestion resolver excludes already-linked destinations; Tasks 1–2 pin this.
3. **Planning ambiguity / absent authoritative Arena context** — REVIEW remains useful but reports alignment as unverified/partial instead of fabricating curricular support; Task 2 pins this.
4. **Unsafe source state** — unknown/student-personal/restricted/failed content never enters detailed review or curriculum matching; Tasks 2 and 4 pin this.
5. **Hidden side effects / extra remote work** — REVIEW renders zero durable mutation and adds no `/api/copilot/library-proposal` or new REVIEW request; Tasks 3–4 pin this.

**Interfaces:**

```ts
export type ContextualReviewRelevanceLevel = 'strong' | 'plausible' | 'weak';
export type ContextualReviewConfidenceLevel = 'high' | 'medium' | 'low';

export interface ContextualReviewPlanningMatch {
  itemId: string;
  kind: string;
  sourceSection: string;
  matchedTerms: string[];
}

export interface ContextualReviewReuseSuggestion {
  targetType: 'uda' | 'lesson';
  targetId: string;
  udaId: string;
  title: string;
  subtitle: string;
  reasons: string[];
}

export interface ContextualDidacticReviewV2 {
  schema: 'registro.contextual-didactic-review/v2';
  sourceId: string;
  context: {
    className: string;
    udaId: string;
    lessonId?: string;
    planningProfileId?: string;
    arenaContextId?: string;
  };
  relevance: {
    level: ContextualReviewRelevanceLevel;
    statement: string;
  };
  rationale: string[];
  alignment: {
    status: 'supported' | 'partial' | 'unverified';
    planningMatches: ContextualReviewPlanningMatch[];
  };
  gaps: string[];
  reuseSuggestions: ContextualReviewReuseSuggestion[];
  confidence: {
    level: ContextualReviewConfidenceLevel;
    reasons: string[];
  };
  limitations: string[];
}

export type ContextualDidacticReviewResolution =
  | { status: 'reviewed'; review: ContextualDidacticReviewV2 }
  | {
      status: 'unavailable';
      reason: 'SOURCE_NOT_PROFESSIONAL' | 'SOURCE_NOT_USABLE' | 'TEACHING_CONTEXT_MISSING';
      limitations: string[];
    };

export interface ResolveContextualDidacticReviewInput {
  source: LibrarySource;
  udas: UdaRecord[];
  teachingContext: ResolvedLibraryTeachingContext | null;
  planningContext: LibraryPlanningContextResolution | null;
}

export function resolveContextualDidacticReview(
  input: ResolveContextualDidacticReviewInput
): ContextualDidacticReviewResolution;
```

The implementation accepts no persistence callback, network client, provider client or memory store.

- [ ] **Step 1: Write RED tests for evidence semantics**

Create tests that assert all of the following:

1. professional `ready` source + explicit current lesson + readable lexical evidence + authoritative Arena curriculum term match → `reviewed`, relevance `strong`, alignment `supported`, confidence `high`;
2. current lesson/UDA/class context with no lexical or curriculum evidence → relevance exactly `weak`;
3. professional source with lexical match but no authoritative curriculum match → relevance `plausible` or `strong` only according to the spec's exact rule, while alignment is not fabricated;
4. ambiguous/unavailable Planning Context → review remains available but alignment `unverified`, with a gap/limitation and confidence reduced;
5. resolved Planning Context with `arenaContext: null` → no claimed curriculum support;
6. current target already linked by the source → still `reviewed` using `resolveLibraryRelevanceTarget()`;
7. reuse suggestions exclude the current target and are capped at three;
8. title-only eligible source can be reviewed, but lack of readable content appears as a gap and prevents `high` confidence;
9. `privacy: 'unknown'` and `privacy: 'student-personal'` → `unavailable/SOURCE_NOT_PROFESSIONAL`;
10. `status: 'restricted'` and `status: 'failed'` → `unavailable/SOURCE_NOT_USABLE`;
11. missing Teaching Context → `unavailable/TEACHING_CONTEXT_MISSING`.

- [ ] **Step 2: Run RED**

```bash

```

Expected: FAIL because the module does not exist.

- [ ] **Step 3: Implement `resolveContextualDidacticReview()`**

Implementation decisions fixed by the spec:

- source eligibility gate occurs before any curriculum/content matching;
- usable statuses are `captured` and `ready`;
- current target is lesson when `teachingContext.lessonId` exists, otherwise UDA;
- current-target evidence comes from `resolveLibraryRelevanceTarget()`;
- reuse candidates come from existing `resolveLibraryRelevance()` and are transformed with `describeLibraryRelevanceCandidate()`;
- reuse suggestions exclude the current target and stop at three;
- curriculum comparison is local and deterministic against authoritative `arenaContext.curricoloItems[].text` only;
- curriculum matches are compact `{ itemId, kind, sourceSection, matchedTerms }`, capped at three;
- `strong` requires lexical current-target evidence plus `CURRENT_LESSON` or at least one specific curriculum match;
- `plausible` requires lexical current-target evidence or one specific curriculum match but does not meet `strong`;
- otherwise relevance is `weak`;
- context presence (`CURRENT_UDA`, `CURRENT_CLASS`, grade match) alone cannot promote above `weak`;
- `high` confidence requires readable source content + lexical current-target evidence + authoritative Planning/Arena context + specific curriculum match;
- `medium` requires at least two evidence families among readable source content, current-target lexical evidence, planning/curriculum evidence;
- otherwise confidence is `low`;
- no raw score leaves the result model;
- limitations always state that the result is a local deterministic support to teacher judgment.

Use a private Italian normalization/tokenization helper for curriculum matching; do not change LIB-03B score weights or public ranking semantics.
